WordPress MU-Plugins Backdoor Campaign — Active Threat

Security

Sucuri identified a sophisticated backdoor campaign targeting /wp-content/mu-plugins/. The attack places a malicious "wp-index.php" that fetches an obfuscated (ROT13) payload from the database, creates an admin user ("officialwp"), installs a self-restoring malicious plugin, and includes a hidden file manager. MU-plugins execute automatically, don't appear in the admin plugin list, and most admins never inspect the directory.

Why it matters: Active threat requiring immediate action. Audit ALL client sites' mu-plugins directories, check for the _hdra_core database option, review admin users for "officialwp", and verify no unknown plugins exist. Standard cleanup may fail because the backdoor reinstalls itself.
via Security Affairs
