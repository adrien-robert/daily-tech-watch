White House Blocks Anthropic's Mythos Expansion to 70 New Organisations

Important

The White House has formally opposed Anthropic's plan to expand access to its Mythos AI model — the cybersecurity-focused model capable of autonomously discovering zero-day vulnerabilities — to roughly 70 additional organisations. Administration officials cited concerns that Anthropic may lack sufficient compute to serve a larger user base without degrading government access, and warned the model could be used to exploit critical infrastructure. Why it matters: Mythos represents a new category of AI capability — autonomous vulnerability discovery at scale. 1M Context Window Beta Retired — Migrate to Claude 4.6 Models

Important

As of April 30, the 1M token context window beta for Claude Sonnet 4.5 and Claude Sonnet 4 has been officially retired. The beta header no longer has any effect on these models, and requests exceeding the standard 200K context window will return an error. Users should migrate to Claude Sonnet 4.6 or Claude Opus 4.6, where the 1M context window is generally available at standard pricing with no beta header required.

Why it matters: If you have API integrations or scripts using the old beta header with Sonnet 4.5 or Sonnet 4 for long-context tasks (e.g., processing large codebases or lengthy client documents), they will break. Update your model strings to claude-sonnet-4-6 or claude-opus-4-6 immediately.
via Claude Platform Docs

CVE-2026-1830: Quick Playground Plugin RCE — Unauthenticated Remote Code Execution

Security

A critical remote code execution vulnerability has been disclosed in the Quick Playground WordPress plugin (all versions up to 1.3.1). Unauthenticated attackers can retrieve a sync code via an unprotected REST API endpoint, then upload arbitrary PHP files using path traversal to gain full server access. The attack requires no authentication and no user interaction — this is a direct path to complete site takeover.

Why it matters: If you or any client site has Quick Playground installed, deactivate and remove it immediately. Even if you don't use it actively, an installed copy is exploitable. Check all managed sites with wp plugin list --status=active via WP-CLI.
via SentinelOne

XSS Vulnerability in WordPress Radio Player Plugin (CVE-2024-13362)

Security

A cross-site scripting vulnerability was disclosed on May 1 affecting the Radio Player plugin (versions ≤ 2.0.82). The XSS is exploitable without authentication but requires user interaction (clicking a crafted link). Update to the latest patched version if this plugin is in use on any client sites.

Why it matters: While lower severity than the Quick Playground RCE, stored or reflected XSS can lead to admin session hijacking. If any client sites use audio streaming features, verify they're not running this plugin or ensure it's updated.
via Managed-WP
