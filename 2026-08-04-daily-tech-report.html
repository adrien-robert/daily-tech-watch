MCP 2026-07-28 Goes Stateless — What It Means for WordPress Workflows

Milestone

The new MCP specification drops the stateful session model for a stateless request/response core. Protocol version and capabilities now travel inline via _meta fields. New features include Multi Round-Trip Requests (MRTR), header-based routing, cacheable list results, and OAuth/OIDC-aligned authorization. Roots, Sampling, and Logging are deprecated (12-month grace period).

Why it matters: WordPress MCP servers (AI Engine, InstaWP, wp-playground) will need to adopt the new stateless spec. The move to standard HTTP means WordPress MCP endpoints can now run on serverless/edge infrastructure — dramatically cheaper hosting for staging environments connected to Claude Code.
