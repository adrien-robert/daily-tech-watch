Kirki Plugin CVE-2026-8206 — Critical Admin Takeover (CVSS 9.8)

Security

A critical vulnerability in the Kirki Freeform Page Builder plugin (versions 6.0.0–6.0.6) allows unauthenticated attackers to hijack administrator accounts via a flawed password reset mechanism. The handle_forgot_password() function accepts attacker-supplied email addresses instead of validating against the account's registered email. Over 500,000 sites are affected, with 150,000 actively vulnerable. Wordfence has confirmed active exploitation — 59 attacks blocked in a single 24-hour window.

Why it matters: If any client site uses Kirki, update to version 6.0.7 immediately. After patching, audit user accounts for unauthorized admin registrations and check for web shells. This is actively exploited in the wild.
via CyberSecurity News

Burst Statistics CVE-2026-8181 — Authentication Bypass (CVSS 9.8)

Security

Wordfence researchers discovered a severe authentication bypass flaw in the Burst Statistics plugin (versions 3.4.0–3.4.1.1) that allows attackers to gain administrator-level access without valid credentials. The vulnerability was introduced on April 23, 2026. Free Wordfence users received firewall protection on June 8; premium users were already covered.

Why it matters: Burst Statistics is a popular privacy-friendly analytics plugin. If you use it on any client site, verify you're running a version past 3.4.1.1 and ensure Wordfence rules are up to date.
