Anthropic Launches Inference Hooks for Enterprise DLP

New

Anthropic released inference hooks on August 5, a beta feature for Claude Enterprise that routes every employee prompt through the organization's own security server for an allow-or-deny verdict before the model sees it. The webhook-based protocol integrates with existing DLP tools including Netskope, Palo Alto Networks, Proofpoint, and Zscaler. Shadow mode, role-based exclusions, and percentage-based rollouts simplify deployment.

Why it matters: Enterprise DLP at the inference layer means Claude can now meet stricter compliance requirements without device-level agents. This could accelerate Claude adoption in regulated industries, expanding the ecosystem for developers building on the API.

ACF 6.8.7 Security Release — Multiple Fixes and New Datastore API

Security

Advanced Custom Fields released version 6.8.7 on August 4 with five security fixes: server-side image validation for Image/Gallery fields, block path attribute protection, HMAC-authenticated encryption replacing base64 fallbacks, context-scoped form saves, and read-permission enforcement on Post Object/Relationship AJAX queries. ACF PRO also gains a new acf/fields wp.data store for reading and writing field values from JavaScript, live preview for block bindings, and REST-based saves with revision support.

Why it matters: If you use ACF (and you do), update immediately. The AJAX permission fix alone could expose draft/private post data to unauthenticated visitors. The new wp.data store is a bonus — it opens the door to richer Gutenberg integrations with ACF field values editable inline in the block editor.
via ACF Blog

PHP 8.5.9 Security Patch — High-Severity SQL Injection in pgsql

Security

PHP 8.5.9 (August 3) patches CVE-2026-17543, a high-severity SQL injection in the PostgreSQL extension affecting pg_insert(), pg_update(), pg_select(), and pg_delete(). It also fixes an out-of-bounds write in BCMath's bccomp() (CVE-2026-17544), a crash from recursive symlinks in Phar (CVE-2026-7260), and an updated libgd (CVE-2026-9672). PHP 8.2, 8.3, and 8.4 received parallel patches.

Why it matters: While the pgsql CVE primarily affects PostgreSQL users, the BCMath and Phar fixes apply to any PHP installation. WordPress sites using bccomp() for price calculations or Phar-based tooling should update. Check with your host — Pantheon, Cloudways, and others have already deployed this patch.
via Pantheon Docs
