Important

WordPress "wp2shell" RCE Chain Actively Exploited — Thousands of Sites Compromised

Security

Attackers are actively exploiting two chained WordPress core vulnerabilities (CVE-2026-63030 REST API batch-route confusion + CVE-2026-60137 SQL injection) that allow unauthenticated remote code execution. WordPress patched these on July 17 via forced auto-updates to 7.0.2/6.9.5/6.8.6, but security firms report tens of thousands of exploitation attempts and 100+ backdoor accounts created across honeypots as of July 20. The bug requires no plugins and no authentication — stock installs without a persistent object cache are exploitable.

Why it matters: Every client site on WordPress 6.9.x or 7.0.x that hasn't updated to 7.0.2/6.9.5 is a live target right now — this is an emergency patch-and-verify task across your entire client portfolio, not a read-later item.
via TechCrunch / The Register / SecurityWeek
