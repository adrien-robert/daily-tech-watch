Broadcom patches a VMware vCenter zero-day exploited since September

🔒 Security

Broadcom fixed CVE-2026-123890, an authentication bypass in the vCenter Directory Service, on 19 Nov in VMSA-2026-0009. Mandiant says a suspected Chinese state-sponsored group, Armory Castle, has exploited it since early September after first breaking in through BeyondTrust Remote Support appliances. Broadcom lists no official workaround.

Why it matters: Nothing to patch on ordinary WordPress hosting, but it is the kind of flaw a hosting provider running VMware would need to fix; you can ask yours if they are exposed.

via BleepingComputer · published Thu 19 Nov

Google will require Android developer verification worldwide from January 2027

⚠️ Breaking

Google says the requirement will roll out in all regions in January 2027. It began blocking installation of unregistered apps in some countries this autumn, and urges developers who have not registered to do so soon.

Why it matters: If you or clients distribute Android apps outside Google Play, developer registration will be needed; otherwise nothing to do.

Claude Code 2.1.329 warns where a folder's hooks are declared

🔄 Update

Released on 19 Nov, version 2.1.329 adds a trust dialog warning that says where a folder's hooks are declared. It also lists scheduled tasks, /loop wakeups and forks in /tasks, and shows the JSON-RPC error message of a remote MCP server that refuses a connection in /mcp.

Why it matters: The hook warning is useful when you open a client repository you did not write; the /mcp error row helps debug WordPress MCP connections.

WordPress 7.2 lets abilities declare required capabilities

🆕 New

A core developer note published on 19 Nov says the Abilities API in WordPress 7.2 gains a required_capabilities argument, checked with current_user_can() before every call, alongside more predictable input handling and JSON output. Input-dependent checks stay in permission_callback.

Why it matters: If you register abilities for Claude to use on client sites, declare the capability there instead of writing it into each permission callback.

via Make WordPress Core · published Thu 19 Nov

ACF 6.8.12 adds a Settings page and turns the Abilities API on by default

❗ Important

ACF 6.8.12, published on 19 Nov, adds an ACF Settings page and enables the Abilities API site-wide, including for every existing field group, post type and taxonomy. Field groups still need Show in REST API turned on for AI tools to read or update their fields. Settings already set in code stay locked.

Why it matters: After updating, client sites expose ACF structures to AI tools without you opting in; to keep that off, disable the setting or add the acf/settings/show_settings filter on client sites.

via ACF · published Thu 19 Nov

Perfmatters 2.7.1 fixes Cloudflare cache purges and cache warmer issues

🔄 Update

Released on 19 Nov, 2.7.1 fixes Cloudflare single-URL purges not invalidating edge HTML, and a sync on a shared zone that deleted another site's rules. The cache warmer now uses a plain Perfmatters/Warmer user agent, to avoid Cloudflare 520 errors on hosts such as SiteGround.

Why it matters: If you tried the Cache (BETA) tab from 2.7.0 behind Cloudflare, update before relying on it.

via Perfmatters · published Thu 19 Nov
