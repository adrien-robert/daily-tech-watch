wp2shell: Critical Pre-Auth RCE Still Being Actively Exploited

Security

The wp2shell vulnerability chain (CVE-2026-63030 REST API batch-route confusion + CVE-2026-60137 SQL injection) allows unauthenticated remote code execution on bare WordPress installs with zero plugins. Affects WP 6.9.0–6.9.4 and 7.0.0–7.0.1. Patches shipped as 6.9.5 and 7.0.2 with forced auto-updates enabled. Both CVEs are on CISA's KEV catalog since July 21, confirming active exploitation in the wild.

Why it matters: This is the most critical WordPress vulnerability in years — pre-auth RCE on a default install. Verify EVERY client site is running 6.9.5+ or 7.0.2+ immediately. Auto-update should have caught it, but confirm manually. If any site disabled auto-updates, it may already be compromised.
via Rapid7
