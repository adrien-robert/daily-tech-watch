Claude Code Mods: Customize Behavior with TypeScript Hooks

Tool

Anthropic launched the Claude Code mods system on October 1. Mods are small TypeScript/JavaScript functions that hook into internal events: rewriting prompts before they reach the model, blocking or retrying tool calls, managing permissions, and adding custom UI panes. Ships with examples like Token Weather (context usage sparkline), Blast Radius (catches destructive commands), and Replay Theater (step through file edit diffs). Requires Claude Code v2.1.287+.

Why it matters: You can build agency-specific mods to enforce sws_ prefix conventions, auto-approve safe commands for WordPress development, add project-specific dashboards, or redact client credentials from tool output. This is a significant extensibility win.
via Anthropic Blog

AI-Discovered CVE in Rejetto HFS Exploited by China-Based Actors Within 24 Hours

Security

Horizon3's team used Anthropic's Mythos AI to discover CVE-2026-61500, a critical session forgery vulnerability in Rejetto HTTP File Server (versions 3.0.0–3.2.0). The flaw allows attackers to recover the session-cookie signing key via predictable Math.random() output and forge admin sessions for RCE. Within 24 hours of disclosure, China-based actors were exploiting vulnerable US hosts.

Why it matters: AI-powered vulnerability discovery is accelerating the exploit cycle dramatically. If any client environments run Rejetto HFS, patch immediately. This also demonstrates the dual-use nature of frontier AI models in security.
via Endor Labs

GitLab AI Gateway Critical RCE Vulnerability (CVE-2026-1868, CVSS 9.9)

Security

A CVSS 9.9 critical vulnerability in GitLab AI Gateway's Duo Workflow Service allows authenticated attackers to achieve arbitrary code execution through crafted Duo Agent Platform Flow definitions. Affects versions 18.1.6–18.3.1 before the patched releases. Fixed in GitLab AI Gateway 18.6.2, 18.7.1, and 18.8.1.

Why it matters: If you or your clients use GitLab with AI features enabled, update immediately. The 9.9 CVSS score means full service compromise is possible. This is a workflow/orchestration parsing issue, not a classic prompt injection — it targets the AI gateway infrastructure itself.
via ThreatCluster

PHP 8.5 Becomes Default on Major Hosting Platforms

Update

As of October 1, PHP 8.5 is now the default version on Clever Cloud and FrankenPHP runtimes. Any PHP application deployed without explicit version specification now runs 8.5. PHP 8.4 leaves active support on December 31, 2026 (security fixes continue until December 2028). PHP 8.5 gets active support through end of 2027.

Why it matters: WordPress sites on managed hosting that auto-updates PHP could be affected. Test client sites for PHP 8.5 compatibility now — especially plugins using deprecated features. Pin PHP versions in deployment configs to avoid surprise upgrades.
