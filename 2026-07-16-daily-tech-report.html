DeepSeek API Migration Deadline: July 24

Deadline

DeepSeek retires the deepseek-chat and deepseek-reasoner model endpoints on July 24 at 15:59 UTC. After that, calls using legacy model names will return errors. Migration is a one-line change: update to deepseek-v4-pro or deepseek-v4-flash. Critical catch: deepseek-reasoner maps to V4-Flash (thinking mode), not V4-Pro.

Why it matters: If you or any clients use DeepSeek in production workflows, automations, or plugins, you have 8 days to update the model parameter. The reasoner-to-Flash mapping is a gotcha that could silently downgrade capability for reasoning-heavy workloads.
via Enterprise DNA

WordPress 7.1 Beta 1 Released — Responsive Styling, React 19, AI Guidelines

Update

WordPress 7.1 Beta 1 landed on July 15, with the final release targeting August 19 at WordCamp US. Major features include: Responsive Styling (style blocks per viewport directly in the editor with a freely resizable device preview), React 19 upgrade (block editor moves to React 19, Classic block deprecated with lazy-loaded TinyMCE), AI Guidelines (site admins can define editorial rules, brand voice, and content standards for AI tooling, with import/export), and WebAssembly media pipeline (native HEIF, JPEGXL, Ultra HDR support via wasm-vips).

Why it matters: The Guidelines feature is directly relevant to AI-powered content workflows — you can define brand voice rules that AI tools respect across your client sites. Responsive Styling eliminates the need for custom CSS breakpoints in many cases. The React 19 upgrade may affect custom Gutenberg blocks. Test in staging before August 19.

Microsoft Patch Tuesday: Record 570 Flaws, 3 Zero-Days (2 Actively Exploited)

Security

Microsoft's July 2026 Patch Tuesday is the largest ever — 570 vulnerabilities across Windows, Office, Azure, SQL Server, Exchange, and SharePoint. Includes 59 Critical flaws and 3 zero-days, two of which are actively exploited: an AD FS elevation of privilege and a SharePoint Server elevation of privilege. SharePoint received the heaviest concentration of critical fixes, including two Critical RCE vulnerabilities.

Why it matters: If you or your clients run Windows servers, on-premises SharePoint, or Exchange, patch immediately — the two actively exploited zero-days are in AD FS and SharePoint. The SharePoint fixes are especially urgent for agencies hosting client intranets or document management on SharePoint Server.
