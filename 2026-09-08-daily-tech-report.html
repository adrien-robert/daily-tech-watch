CISA Adds LiteLLM MCP Auth Bypass to KEV Catalog

Security

CVE-2026-59822 (CVSS 8.8) is an authentication bypass in LiteLLM's MCP Streamable HTTP endpoint. An unauthenticated attacker can forge a Bearer token to reach MCP tooling without a valid key, listing and calling configured MCP tools. Exploited in the wild. Patch to v1.84.0 or block /mcp/ routes at your reverse proxy. Federal agencies have until September 16 to remediate.

Why it matters: If you use LiteLLM as an LLM proxy in any client project or internal tool, this is a patch-now situation. The flaw exposes every MCP tool behind the proxy to unauthenticated access.
via CISA
