Microsoft Warns: Poisoned MCP Tool Descriptions Can Make AI Agents Leak Data

Security

Microsoft Incident Response researchers disclosed that attackers can hijack AI agents by injecting malicious instructions into MCP tool descriptions. Since MCP mixes instructions and data in the same context, a poisoned description can steer an agent to exfiltrate sensitive data (e.g., invoices, credentials) without triggering re-approval. A real-world case already exists: an npm package called "postmark-mcp" silently BCC'd every email to an attacker. Starting in July, Microsoft requires developer-signed manifests with content hashes for all MCP servers in its agent frameworks.

Why it matters: If you use third-party MCP servers with Claude Code (WordPress MCP adapter, database connectors, etc.), audit their descriptions and pin versions. A single compromised server could leak client site data or credentials through your AI agent.
via The Hacker News
