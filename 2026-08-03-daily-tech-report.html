MCP 2026-07-28 Specification Released — Protocol Goes Stateless

Breaking

The largest revision to the Model Context Protocol since launch is now final. MCP is now stateless at the protocol layer, removing the initialize/initialized handshake and the Mcp-Session-Id header. The spec adds multi-round-trip requests, header-based routing, cacheable list results, authorization hardening, and a formal extensions framework. All four Tier 1 SDKs shipped support on publication day.

Why it matters: If you run any MCP servers — including WordPress MCP integrations or the new Bricks 2.4 MCP — this is a breaking change. Existing servers built on the old stateful handshake will need updates. Plan your migration during the 10-week validation window.
via Model Context Protocol Blog

Security
