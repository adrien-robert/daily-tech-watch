ShapedPlugin Pro plugins backdoored in supply chain attack (CVSS 10.0)

Security

The ShapedPlugin update infrastructure was compromised, injecting backdoors into Pro plugin builds since May 21. Affected products: Product Slider Pro for WooCommerce (before 3.5.4), Real Testimonials Pro (3.2.5), and Smart Post Show Pro (before 4.0.2). The malware installs a webshell, Tiny File Manager, and Adminer, then steals WordPress credentials, 2FA secrets, database credentials, and WooCommerce order data. CVE-2026-49777 (CVSS 10.0).

Why it matters: If any client site uses ShapedPlugin Pro products, check immediately. The free WordPress.org versions are not affected. Update to the patched versions, rotate all credentials (WordPress admin, database, SMTP), and scan for webshells. This attack pattern — compromising the vendor's build pipeline — is accelerating in the WordPress ecosystem.
via Wordfence

Core Web Vitals: INP methodology refined — only 55.9% of sites pass all three

Trend

The May 2026 CrUX release (published June 9) refined how INP (Interaction to Next Paint) measures sustained interaction latency, weighting repeated slow interactions more heavily. Current pass rates: LCP 68.6%, CLS 81.3%, INP 86.6% individually, but only 55.9% of origins pass all three together. Mobile scores now carry more weight in rankings.

Why it matters: The INP methodology change means sites with intermittently slow interactions (like complex Bricks Builder forms or WooCommerce checkout flows) may see their scores drop. Run Lighthouse on your client sites and prioritize any that fall below the INP threshold — especially on mobile.
via RivuletIQ
