European Commission hit by cyberattack using AI pentest tool ARTEX

❗ Important

The European Commission has had more than 10 days of disruption after attackers used ARTEX, a publicly available AI penetration-testing framework, as first reported by Politico. Staff systems for payslips and medical reimbursement were taken offline, and the Commission has not said whether personal data was taken. The FBI found more than 1,600 ARTEX consoles exposed to the internet.

Why it matters: Nothing specific to do today. The FBI describes attackers using this tool going from picking a target to privileged access in under three hours, which leaves less room for slow patching on client sites.

Microsoft Agent Framework PyPI package compromised to steal credentials

🔒 Security

Attackers published two malicious versions, 1.26.1 and 1.26.2, of Microsoft's Agent Framework package on PyPI on 17 Nov. They ran a credential stealer at Python startup, even without importing the package. PyPI quarantined both, and the safe version is 1.26.0.

Why it matters: Only matters if you or a tool of yours installed agent-framework on 17 Nov. If so, rotate any credentials in reach of that environment.

WordPress 7.1.5 fixes 20 security issues, including an unauthenticated flaw that could lead to RCE

🔒 Security

WordPress 7.1.5, released on 18 Nov, lists 20 security fixes. They include an unauthenticated privilege escalation via Template Part block attributes that could lead to remote code execution, SQL injection in WP_Meta_Query and in Customizer changeset previews, and an unauthenticated stored XSS via shortcode attributes in comments. Fixes were backported to all branches eligible for security fixes, through 4.7, and are shipping as they become ready.

Why it matters: Update every client site today, or check that background updates have applied. The next major release, 7.2, is planned for 8 Dec.

via WordPress News · published Wed 18 Nov

PHP 8.5.13, 8.4.28, 8.3.37 and 8.2.36 fix 18 CVEs, seven rated Critical

🔒 Security

PHP released security updates on 19 Nov for all supported branches. Patchstack counts 18 CVEs, seven of them Critical at CVSS 9.2. It says none are WordPress bugs and the fix is a host-level update, and picks out two as reachable on ordinary hosting setups: a timezone cache use-after-free (CVE-2026-129496) and PHP-FPM request smuggling (CVE-2026-129289).

Why it matters: Ask your hosts to move to the fixed PHP versions this week. Until they do, check that FastCGI connection reuse is off (fastcgi_keep_conn in nginx, enablereuse in mod_proxy_fcgi), which is the precondition for the request smuggling bug.

via Patchstack · published Thu 19 Nov

NGINX patches critical HTTP/2 flaw that allows remote code execution

🔒 Security

NGINX 1.31.9 and 1.30.7, released on 18 Nov, fix CVE-2026-123007, a memory corruption bug in HTTP/2 flow control present in every release from 1.9.5 to 1.31.8. Public proof-of-concept code exists, but The Hacker News reports no attacks so far and no listing in CISA's exploited-vulnerabilities catalog. Four more flaws are fixed in the same releases.

Why it matters: Only matters if a client's host runs NGINX with HTTP/2 enabled. Ask your hosts whether they have moved to the fixed versions.

Chrome 158 drops XSLT, so WordPress sitemaps now show as raw XML

❗ Important

Chrome 158 began rolling out on 17 Nov without client-side XSLT, so WordPress core and SEO plugin sitemaps that rely on an .xsl stylesheet display as unstyled XML. Search Engine Journal says crawlers do not use XSLT and indexing is unaffected. WordPress 7.2, planned for 8 Dec, removes core's XSLT stylesheet, and Yoast 28.9 replaces it with CSS.

Why it matters: If a client reports a broken sitemap, it is not. Check Search Console under Indexing, then Sitemaps, for a Success status instead of changing anything.

via Search Engine Journal · published Thu 19 Nov

✨ Quick win

Open a client's wp-sitemap.xml in Chrome and check the Sitemaps report in Search Console, so you can answer a raw-XML complaint with a screenshot of the Success status.
