CVE-2026-87902: Critical WordPress RCE Under Active Exploitation

Security

WordPress 7.1.2 (released Sep 22) patches CVE-2026-87902, a CVSS 9.2 critical vulnerability in get_page_template() that lets unauthenticated attackers traverse paths to include arbitrary PHP files and achieve remote code execution. Attackers deployed functional PHP webshells within 48 hours of disclosure. Over 350,000 sites remain exposed. The flaw affects every WordPress version from 4.7.0 through 7.1.1, and the fix has been backported to version 4.7.

Why it matters: This is a "drop everything and patch" situation. If any of your client sites are still running WordPress < 7.1.2, they are actively at risk of being compromised with webshells. The exploit is trivial, public scanning tools are in circulation, and attackers are using pearcmd.php to write malicious files to disk. Update ALL sites immediately.
via Patchstack
