Gravity SMTP Under Mass Exploitation — 17 Million Attacks Blocked

Security

CVE-2026-4020 in the Gravity SMTP plugin allows unauthenticated attackers to extract API keys, OAuth tokens, and full configuration data via an unprotected REST API endpoint. Wordfence blocked over 17 million exploit attempts, with 4 million in a single day on June 7. The plugin is installed on 100,000+ WordPress sites. Patch: update to version 2.1.5 or later.

Why it matters: If you or any client sites use Gravity SMTP, update immediately to version 2.1.5+ and rotate all API keys, secrets, and OAuth tokens configured in the plugin's email connectors. The exploit is trivial — a single unauthenticated REST API call returns ~365 KB of sensitive configuration data.
via The Hacker News
