Security

A critical unauthenticated Remote Code Execution vulnerability was disclosed in the "Custom css-js-php" plugin (versions up to 2.0.7). Exploited via SQL injection, it enables complete site takeover without authentication.

Why it matters: Audit all client sites immediately. If any site uses "Custom css-js-php," remove or update it today. This is an unauthenticated RCE — the most dangerous class of WordPress vulnerability. Run wp plugin list across all sites to check.
