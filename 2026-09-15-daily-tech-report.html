Gutenberg 23.8 Deprecates InnerBlocks Props — Migrate Before WordPress 7.2

Deadline

Gutenberg 23.8 replaced the InnerBlocks template and templateInsertUpdatesSelection props with block type settings of the same names. The old props are officially deprecated and will be removed before WordPress 7.2 ships (Beta 1: October 20-22). Gutenberg 23.9 also added a declarable API for block keyboard shortcuts.

Why it matters: If you've built custom Gutenberg blocks using InnerBlocks template props, start migrating now. The October beta deadline is closer than it looks — audit your blocks with grep -r "InnerBlocks" --include="*.js" across your projects.

France E-Invoicing: Reception Obligation Now Active for All VAT-Registered Businesses

Deadline

Since September 1, 2026, all VAT-registered businesses in France must be able to receive electronic invoices through an accredited platform (PDP) certified by DGFiP. A PDF sent by email does not qualify. Issuance obligations begin now for large enterprises and ETIs, extending to SMEs and micro-enterprises in September 2027.

Why it matters: As an EURL, you must now be set up to receive e-invoices from clients and suppliers who are already issuing them. Verify that your accounting platform supports the reform. You have until September 2027 to issue e-invoices yourself, but set up early to avoid the last-minute rush.
