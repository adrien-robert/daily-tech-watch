Critical Auth Bypass in Temporary Login Plugin — CVE-2026-7567 (May 5)

Security

A critical authentication bypass vulnerability disclosed on May 5, 2026 affects the WordPress Temporary Login plugin (versions ≤ 1.0.0). Exploitation enables full account takeover, arbitrary code execution via plugin installs, data exfiltration, and malware injection.

Why it matters: If any of your client sites use the Temporary Login plugin, update immediately or deactivate. This is an unauthenticated bypass — attackers don't need credentials to exploit it.

WordPress.org Shuts Down Essential Plugin Portfolio — Supply-Chain Backdoors

Security

WordPress.org's Plugins Team has permanently closed every plugin under the Essential Plugin portfolio after discovering supply-chain backdoors planted across 30+ plugins. The malicious code was injected after ownership quietly changed and lay dormant for eight months before detection.

Why it matters: This is a reminder to audit plugin ownership changes. Run wp plugin list --status=active on all client sites and cross-reference against the Essential Plugin portfolio list. Deactivate and replace any matches immediately.
