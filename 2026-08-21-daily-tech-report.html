Claude Code v2.1.237 Ships "Concise" Output Style

Tool

Anthropic shipped a built-in "Concise" output style in Claude Code v2.1.237. Claude now leads with the result, keeps responses short, and skips preamble and narration while doing the work just as thoroughly. Full detail is still available on request. The release also fixes prompt caching for sessions using an LLM gateway or custom base URL.

Why it matters: If you use Claude Code daily, this is an immediate quality-of-life win. Enable it via /config → Output style, or set "outputStyle": "Concise" in settings.json. Less scrolling, faster feedback loops.
via Claude Code Changelog

Bricks 2.4 Beta 3: MCP AI Abilities Now Include PHP Execution

Important

Bricks Builder 2.4 beta 3 dropped yesterday with major AI enhancements. MCP-compatible clients (Claude Code, Cursor, Copilot) can now create and edit Bricks content through a set of AI Abilities covering pages, elements, templates, components, global data, design systems, dynamic data, query loops, navigation menus, WooCommerce setup, and HTML-to-Bricks conversion. Beta 3 adds an optional PHP execution ability for deeper WordPress inspection and configuration.

Why it matters: This is the bridge between Claude Code and Bricks Builder you've been waiting for. You can now use Claude Code as an MCP client to directly build and edit Bricks pages, scaffold components, and even run PHP to inspect plugins and hooks — all from the terminal. Enable PHP execution via the BRICKS_ENABLE_EXECUTE_PHP_ABILITY constant (staging first!). Also includes remote component libraries and new WooCommerce v2 elements.
via Bricks Builder

WordPress 7.1 "Mary Lou" Released

Milestone

WordPress 7.1, named after jazz pianist Mary Lou Williams, landed on August 19. Headline features include interactive states styling (:hover, :focus, :active) from the editor UI without writing CSS, two new core blocks (Tabs and Playlist with waveform visualization), inline collaboration notes with @mentions and suggestion mode, and a free-form image cropper. React 19 upgrade was deferred — 7.1 stays on React 18.3.

Why it matters: Interactive states styling from the editor is a game-changer for Gutenberg-based sites — no more custom CSS for hover effects. The Tabs block is a long-awaited addition. Test on staging before updating client sites; the React 19 deferral means plugin compatibility should be stable.
via WordPress.org

Gutenberg 23.8: Shareable Revision URLs & Code Diff View

Update

Gutenberg 23.8 (August 19) adds shareable URLs for visual revisions in both the post editor and site editor, plus an in-editor code diff view. You can now link directly to a specific revision and compare content changes at the code level without leaving the editor. These features are slated for backport to WordPress 7.1.

Why it matters: Shareable revision links make client review workflows much smoother — send a client a direct link to see exactly what changed. The code diff view is useful for debugging template changes and tracking content edits across team members.
via Make WordPress Core

Google August 2026 Spam Update Rolling Out

Important

Google began rolling out its August 2026 Spam Update on August 18, the third spam update this year. It applies globally across all languages and regions. No new spam policy types were introduced — Google is refining its automated systems to better enforce existing policies (unchanged since December 2025). The rollout is expected to complete within a few days.

Why it matters: Monitor your clients' rankings over the next few days. A ranking decline after August 18 doesn't automatically mean link issues — this isn't a dedicated link spam update. Focus on content quality and existing spam policy compliance. Check Google Search Console for any manual actions or unusual drops.
via Search Engine Journal
