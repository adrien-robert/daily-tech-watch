Active Exploitation Campaign Targeting WordPress Plugins

Security

A large-scale exploitation campaign is actively weaponizing known vulnerabilities in WordPress plugins. Attackers chain unauthenticated file upload, RCE, SSRF, and deserialization vulnerabilities to deploy webshells granting persistent remote access. SMBs worldwide have been impacted.

Why it matters: Active, ongoing threat. Audit all client sites immediately for unpatched plugins and check for webshells. These are public CVEs with available fixes — the issue is speed of patching.
via GBHackers

Stealthy WordPress MU-Plugins Backdoor Campaign

Security

Security researchers discovered a backdoor targeting /wp-content/mu-plugins/. A malicious "wp-index.php" fetches an obfuscated payload, creates a hidden admin user ("officialwp"), and force-installs a self-healing plugin that restores the backdoor if removed. MU-plugins don't appear in the admin plugin list.

Why it matters: Standard plugin audits will not catch this — mu-plugins are invisible in the admin panel. Audit the mu-plugins directory on all client sites, review user accounts for unauthorized admins, and check the database for the _hdra_core option.
via Sucuri
