MCP 2026-07-28 Final Spec Drops in 5 Days — Major Breaking Changes

Deadline

The MCP specification release candidate rewrites the protocol to be stateless at the core layer. Sessions are removed, the initialization handshake is dropped, Roots/Sampling/Logging are deprecated, and authorization aligns with OAuth/OIDC. New extensions include MCP Apps (server-rendered UIs) and Tasks (long-running work). The final spec ships July 28 with a 12-month deprecation window.

Why it matters: If you've built any MCP integrations (WordPress MCP servers, Bricks MCP connections), review the breaking changes now. The stateless redesign is good news long-term (simpler infrastructure, standard load balancers), but existing sessions-based setups will need migration within 12 months. The tasks/list removal and error code changes could break existing tooling.
via MCP Blog

Gutenberg 23.6: Grid Layout Gets "Fill Available Space" Toggle

New

Gutenberg 23.6, released July 22, adds an autoFit layout property that switches grid column behavior from auto-fill to auto-fit. This gives theme authors more precise control over responsive grid layouts. The release also includes flex vertical alignment controls in the inspector. This change has landed in Core for WordPress 7.1.

Why it matters: The auto-fit toggle solves a common Gutenberg grid frustration where columns don't expand to fill remaining space. If you build custom block themes or use Gutenberg for client layouts, this is a direct workflow improvement — fewer CSS overrides needed for responsive grid behavior.
