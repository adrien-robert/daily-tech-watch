Import/Export Plugin Privilege Escalation — CVE-2026-7641

Security

A privilege escalation vulnerability (CVE-2026-7641) in the WordPress Import/Export plugin allows authenticated users to modify user roles and metadata without proper authorization checks. The flaw lets any logged-in user elevate their privileges to administrator. Patched in version 2.0.9.

Why it matters: Any authenticated user — including subscribers — can escalate to admin on affected sites. If any of your client sites use the Import/Export plugin, update to v2.0.9 immediately. Run wp plugin list --status=active | grep import-export across your fleet.
