OpenAI Assistants API Sunsets Today — Migrate Now

Deadline

The OpenAI Assistants API officially shuts down today, August 26, 2026 — exactly one year after the deprecation notice. All Assistants, Threads, and Runs endpoints will stop responding. Developers must migrate to the stateless Responses API, which now includes native MCP support, code interpreter, and persistent conversations via the separate Conversations API.

Why it matters: If any client projects or internal tools still use the Assistants API, they will break today. The Responses API is the replacement — it's stateless by default and includes built-in MCP server support, making it more aligned with how agents are built in 2026.

A2A Protocol Joins Agentic AI Foundation Alongside MCP

Milestone

Google's Agent-to-Agent (A2A) protocol has formally joined the Linux Foundation-directed Agentic AI Foundation (AAIF), placing it alongside Anthropic's MCP under neutral governance. AAIF now counts 250+ members including AWS, Anthropic, Google, Microsoft, and OpenAI. A2A handles horizontal agent-to-agent communication while MCP handles vertical agent-to-tool integration.

Why it matters: The two dominant agent protocols are now under one roof. This consolidation means building agent workflows that combine MCP (connecting to WordPress, databases, APIs) with A2A (orchestrating multiple agents) will follow a single standards body — reducing fragmentation risk for early adopters.
