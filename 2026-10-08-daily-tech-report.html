WordPress 7.1.3 Security Release — 7 Fixes Including XSS & SQL Injection

Security

WordPress released 7.1.3 on October 6 with 7 security fixes and 4 bug fixes. Patched vulnerabilities include a stored cross-site scripting (XSS) bug on the Comments screen and a second-order SQL injection in the WXR export tool. Backports shipped for branches 5.0 through 7.0 (including 7.0.7). No CVE IDs published yet.

Why it matters: Update all client sites immediately. The stored XSS on the Comments screen could be exploited by any user who can submit comments, and the SQL injection in WXR export affects anyone running exports. Both are core vulnerabilities — no plugin required.
via WordPress.org
