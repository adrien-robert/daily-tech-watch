WordPress 7.0.4 Patches Critical RCE via Imagick

Security

WordPress 7.0.4 fixes CVE-2026-65640 (CVSS 8.8) — an authenticated remote code execution vulnerability where Author-level users can execute arbitrary code by uploading a malicious Postscript file processed by Imagick + Ghostscript. The flaw affects every WordPress branch back to 4.7. This comes on top of the 7.0.3 release (Aug 6) which patched 12 vulnerabilities including a pre-auth XSS on the login screen (CVE-2026-64638, CVSS 8.9).

Why it matters: If any of your client sites run Imagick with Ghostscript and have Author-level users, they are vulnerable to remote code execution. Update all managed sites to 7.0.4 immediately. Check Imagick/Ghostscript status with phpinfo() or WP Site Health.
via SecurityWeek
