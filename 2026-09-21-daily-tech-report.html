Plugin4Shell: Zero-Click RCE in AI Coding Agents — Claude Code & Codex Patched, Copilot Still Vulnerable

Security

Security firm AIR disclosed Plugin4Shell (Sept 18), a zero-click remote code execution flaw that bypasses SHA-pinning in plugin systems across four major AI coding agents. The attack creates a Git branch whose name matches a plugin's commit hash, tricking the agent into installing malicious code. Claude Code auto-updates plugins in the background, making it exploitable without user interaction.

Why it matters: Anthropic patched Claude Code in v2.1.179 and OpenAI patched Codex in v0.146.0. However, GitHub Copilot remains unpatched. If you use Copilot alongside Claude Code, update immediately and audit any third-party plugins. Google deprecated Gemini CLI entirely and will not patch.

WordPress 7.1.1: Critical Stored XSS in wpautop() — Update Immediately

Security

WordPress 7.1.1 (released Sept 17) patches 11 security vulnerabilities and 17 core bugs. The headline fix is CVE-2026-93485: an unauthenticated stored XSS in wpautop(), the function that converts line breaks to paragraphs on nearly all WordPress content. An attacker can inject script via comments (subject to moderator approval). Other fixes include a contributor-level arbitrary post overwrite and a REST API path traversal.

Why it matters: The wpautop() XSS is critical because it affects a function used on every WordPress page. If comment moderation isn't strict, malicious scripts could execute in admin browsers, leading to session theft or unauthorized actions. Update all client sites to 7.1.1 immediately — this is the most impactful WordPress security release in months.
via Patchstack
