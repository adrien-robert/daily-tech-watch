Claude Code Ships Nested Sub-agents (5 Levels Deep) and Ultracode Mode

New

Claude Code sub-agents can now spawn their own sub-agents up to 5 levels deep, announced June 9 by Boris Cherny. The motivation is context management — each sub-agent gets a fresh context window. Additionally, the new ultracode setting (v2.1.160) combines xhigh effort with automatic workflow orchestration, letting Claude plan and execute multi-step tasks without manual keyword triggers.

Why it matters: Nested sub-agents are a game-changer for complex WordPress projects — imagine one agent scaffolding a plugin while a sub-agent handles ACF field registration and another writes unit tests, all coordinated automatically.

Bricks Builder 2.3.7 Released — WP 7.0 Compatibility Fixes

Update

Released June 11, Bricks 2.3.7 focuses on compatibility and regression fixes for WordPress 7.0. Key fixes include unexpected default styles in the block editor since WP 7.0, component query loop regressions, Query Filter issues, WooCommerce query fixes, and builder UI improvements. Why it matters: If you updated to WordPress 7.0 and noticed styling glitches in the block editor or broken component query loops, update Bricks to 2.3.7 immediately. This is a critical compatibility patch for WP 7.0 users.
