AI Coding Tools Hit by Sandbox Escape Vulnerabilities

Security

Pillar Security disclosed sandbox bypass vulnerabilities affecting Cursor (CVE-2026-48124), OpenAI Codex, Google Gemini CLI, and Antigravity. A malicious workspace can configure hooks that execute local commands in the user's context when an agent turn ends, enabling sandbox escape and host compromise. Why it matters: If you use Cursor (or any of these tools), update immediately. The vulnerability allows planted hook configurations to execute arbitrary code outside the agent sandbox with your user privileges. This is a real RCE vector, not theoretical.

WordPress wp2shell RCE Under Active Exploitation — Update to 7.0.2 Now

Security

Public exploits for the critical "wp2shell" vulnerability chain (CVE-2026-63030 + CVE-2026-60137) are now widely available, and multiple security firms confirm mass exploitation in the wild since July 18. The chain combines a REST API batch-route confusion bug with a SQL injection flaw to achieve unauthenticated remote code execution on default WordPress installations. Attackers are deploying webshells, uploading malicious plugins, and exfiltrating credentials. WordPress 6.9.0–6.9.4 and 7.0.0–7.0.1 are affected.

Why it matters: This is a critical, actively exploited RCE affecting all client sites running WordPress 6.9.x or 7.0.0–7.0.1. Update every site to 7.0.2 (or 6.9.5) immediately. No plugins needed to exploit — this targets WordPress Core itself. Check all client sites today.
via BleepingComputer
