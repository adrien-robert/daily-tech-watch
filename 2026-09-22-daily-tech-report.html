Plugin4Shell: Zero-Click RCE Hits Claude Code, Codex, Copilot & Gemini CLI

Security

AIR Security researchers disclosed Plugin4Shell, a supply-chain vulnerability that lets attackers swap malicious plugin code past SHA-pinning checks in four major AI coding agents. The bug exploits Git's branch-name resolution: an attacker creates a branch whose name matches the 40-character commit hash, and the agent checks out the malicious branch instead of the pinned commit. Anthropic (Claude Code 2.1.179) and OpenAI (Codex 0.146.0) have patched; GitHub Copilot and Gemini CLI remain unpatched.

Why it matters: If you use Claude Code with third-party MCP plugins, update to v2.1.179+ immediately. This is the first supply-chain attack vector specific to the AI agent ecosystem and affects the tools you use daily.
via CybersecurityNews

WordPress 7.1.1: Critical Click2Shell Security Fix (CVSS 9.6)

Security

WordPress 7.1.1 dropped on September 17 with 11 security fixes, 17 core bug fixes, and 19 block editor fixes. The headline is Click2Shell — a CSRF-to-RCE chain (CVSS 9.6) that silently installs an attacker-chosen theme and executes arbitrary PHP when a logged-in admin clicks a malicious link. Separately, the older WP2Shell vulnerabilities (CVE-2026-63030, CVE-2026-60137) are being actively exploited in the wild with public PoC exploits available. All WordPress versions 6.0–7.1.0 are affected.

Why it matters: CVSS 9.6 critical with active exploitation of related flaws. Update every client site to 7.1.1 today. Auto-updates should handle it, but verify manually — this is the most severe WordPress vulnerability in months.
via Patchstack
