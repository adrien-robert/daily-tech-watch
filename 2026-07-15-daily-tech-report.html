Deadline

Why it matters: If you use DeepSeek in any automated pipeline, agent workflow, or client project, search your codebase now. The aliases have been forwarding to V4 since April, so behavior won't change — but the old names will hard-fail in 9 days.

MCP Specification Goes Stateless — Final Spec July 28

Important

The MCP specification release candidate removes the Mcp-Session-Id header and protocol-level sessions entirely. Remote MCP servers can now run behind plain round-robin load balancers without sticky sessions or shared session stores. New Mcp-Method headers enable routing and rate-limiting without opening request bodies. Final spec ratifies July 28.

Why it matters: If you run WordPress MCP servers (via the official MCP Adapter or third-party plugins), the stateless change simplifies scaling but may require updates to session-dependent implementations. Review your MCP setup before July 28.
