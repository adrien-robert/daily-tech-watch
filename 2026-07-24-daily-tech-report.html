wp2shell Exploitation Grows — Public PoCs Fuel Mass Scanning Campaigns

Security

The wp2shell pre-auth RCE chain (CVE-2026-63030 + CVE-2026-60137) continues to be actively exploited in the wild. Public proof-of-concept exploits on GitHub have fueled mass scanning from 13+ unique IPs across multiple countries. Both CVEs were added to CISA's Known Exploited Vulnerabilities catalog on July 21. Attackers are deploying persistent webshells on vulnerable WordPress 6.9.0–6.9.4 and 7.0.0–7.0.1 installations.

Why it matters: This is a critical, actively exploited vulnerability affecting WordPress Core itself — no plugin required. Verify every client site is running WordPress 6.9.5 or 7.0.2. If immediate patching isn't possible, block the /wp-json/batch/v1 endpoint at your WAF. The forced auto-update was enabled, but manual verification is essential.
via BleepingComputer

WordPress 7.1 Beta 1 landed on July 15 with the centerpiece being the migration from React 18 to React 19 in the Gutenberg block editor.
