WordPress 7.1.2: Critical RCE Vulnerability — Verify Your Sites Are Patched

Security

CVE-2026-87902 (CVSS 9.2) affects WordPress 4.7.0 through 7.1.1. An unauthenticated attacker can manipulate page template selection to include arbitrary PHP files, achieving remote code execution without any login or plugin vulnerability. WordPress 7.1.2 was released September 22 with backports to 4.7. Auto-updates should have applied this, but manual verification is critical.

Why it matters: CVSS 9.2 with no authentication required — this is as serious as WordPress vulnerabilities get. Every client site you manage should be verified as running 7.1.2+. Check today, not tomorrow.
via Cybersecurity News
