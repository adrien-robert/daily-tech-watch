Security

WordPress 7.1.2 patched a critical local file inclusion vulnerability (CVSS 9.2) that allows unauthenticated remote code execution under specific server/theme conditions. Why it matters: This affects a decade of WordPress releases. If any of your client sites are not yet on 7.1.2, update them immediately. The vulnerability is being actively exploited in the wild — this is not theoretical.
