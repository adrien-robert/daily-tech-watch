MCP 2026-07-28 Release Candidate: Protocol Goes Stateless

Milestone

The MCP specification release candidate drops the session ID header entirely — any request can now hit any server instance. This removes the need for sticky sessions and shared session stores. CRITICAL: wp2shell Pre-Auth RCE — Update to WordPress 7.0.2 / 6.9.5 Immediately

Security

WordPress 7.0.2 and 6.9.5 (released July 17) patch wp2shell, a critical pre-authentication remote code execution chain. CVE-2026-63030 (REST API batch-route confusion) + CVE-2026-60137 (SQL injection) together allow anonymous attackers to execute arbitrary code on default installs — no login, no plugins, no special configuration required. WordPress.org has enabled forced auto-updates for affected versions.

Why it matters: Every WordPress 6.9.x and 7.0.x site is vulnerable until patched. Verify that ALL client sites have auto-updated to 7.0.2 or 6.9.5. Even with forced updates, sites with disabled auto-updates or custom configurations may not have received the patch. Check every site today.
via The Hacker News
