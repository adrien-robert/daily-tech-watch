Cascade (Windsurf) Reaches End-of-Life Today — Migrate to Devin Local

Deadline

Cascade, the local AI agent that powered Windsurf (now rebranded to Devin Desktop since June 2), officially reaches end-of-life today, July 1. Any CI pipelines, automation scripts, or workflow rules that explicitly invoke Cascade must be migrated to Devin Local. The replacement claims 30% better token efficiency and adds parallel subagents.

Why it matters: If you or your clients use Windsurf/Cascade in any automated workflow, scripts will break today. Interactive editor use migrated automatically, but named automations need manual updates.

Google Stitch MCP Server Released — AI UI Design Directly from Claude Code

Tool

Google released an official MCP server and SDK for Stitch, its free AI-native UI design tool. You can now prompt Claude Code with requests like "design and implement a settings page" — the MCP server calls Stitch to generate high-fidelity UI screens, then Claude Code implements the design in your codebase. Supports HTML, Tailwind, Vue, Angular, Flutter exports. Uses your standard 350 generations/month quota.

Why it matters: This bridges the design-to-code gap for WordPress agencies. You can generate polished UI mockups via voice or text in Claude Code, export the HTML/CSS, and convert them into Bricks Builder components or Gutenberg blocks — all without leaving your terminal.
via Justin McKelvey
