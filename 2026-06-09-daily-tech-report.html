Kirki Plugin CVE-2026-8206: CVSS 9.8, Actively Exploited

Security

A critical privilege escalation vulnerability in the Kirki Freeform Page Builder plugin (versions 6.0.0–6.0.6) allows unauthenticated attackers to take over any admin account via a flawed password reset mechanism. The attack requires a single HTTP request with a known username. Wordfence has blocked 222+ attempts in 24 hours, and approximately 150,000 sites remain actively vulnerable out of 500,000+ affected.

Why it matters: If any of your client sites use the Kirki plugin, update to version 6.0.7 immediately. This is a trivially exploitable, unauthenticated admin takeover — the most dangerous class of WordPress vulnerability. Check all sites today.
via BleepingComputer

Deadline

All French businesses — including EURLs and micro-entrepreneurs — must be able to receive electronic invoices (Factur-X, UBL, or CII formats) through certified Partner Dematerialization Platforms (PDPs) starting September 1, 2026.
