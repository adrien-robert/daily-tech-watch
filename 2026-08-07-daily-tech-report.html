Claude Code v2.1.223 — Focus View, Security Fixes, and /fork Redesign

Update

Claude Code ships a new Focus view (Ctrl+Alt+F) that collapses tool activity behind a per-turn summary with a live indicator, keeping the chat clean while you work. Security-wise, permission checks now block commands hiding behind invisible characters or tabs, and worktree-isolated sessions can no longer run destructive git commands against the main checkout. The /fork command has been redesigned to copy your conversation into a new background session, while the old in-session subagent behavior moves to /subtask. New safety caps limit WebSearch calls (200/session) and subagent spawns (200/session) to prevent runaway loops.

Why it matters: Focus view is a major quality-of-life improvement for daily Claude Code use — less noise, same power. The security fixes close a real permission-bypass vector. Update your CLI to pick these up.

WordPress 7.0.3 Security Release — 12 Vulnerabilities Patched, Including CVSS 8.9 Login XSS

Security

WordPress 7.0.3 dropped yesterday (August 6) with fixes for 12 security vulnerabilities. The most critical is CVE-2026-64638 (CVSS 8.9): a pre-authentication reflected XSS on the login screen that can lead to PHP code execution via the plugin/theme editor if an admin clicks a malicious link. Other fixes cover stored XSS, privilege escalation, information disclosure, CSS injection, email verification bypass, and server-side request forgery. Every WordPress version from 4.7 through 7.0.2 is affected. Patches have been backported to older branches.

Why it matters: A pre-auth XSS on the login page with a path to code execution is as serious as it gets for WordPress. Update every client site immediately — don't wait for auto-updates. Verify 7.0.3 is applied across all your managed installations today.
via Search Engine Journal
