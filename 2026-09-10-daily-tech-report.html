CVE-2026-19949: 3.25M Sites Still Vulnerable — All-in-One WP Migration SQL Injection

Security

A critical SQL injection vulnerability (CVSS 8.8) in All-in-One WP Migration affects all versions up to 7.109. The patch (v7.110) has been available since August 20, but only ~35% of the 5M+ installs have updated, leaving roughly 3.25 million sites exposed. Authenticated attackers with low privileges can exfiltrate the entire WordPress database via the archive restore functionality.

Why it matters: If any of your client sites use All-in-One WP Migration, update to v7.110 immediately. With modern exploit tooling, the window between disclosure and active exploitation is now measured in hours, not weeks.
via eSecurity Planet

CVE-2026-15748: Forminator RCE Exposes 300K WordPress Sites

Security

A critical arbitrary file upload vulnerability (CVSS 9.8) in Forminator plugin allows unauthenticated remote code execution via malicious PHP uploads on sites with forms containing both File Upload and Select fields. Patched in v1.56.2 (July 31), but roughly half of 600K+ installs remain vulnerable. No in-the-wild exploitation reported yet.

Why it matters: CVSS 9.8 is as critical as it gets. If you use Forminator on any client site, update immediately. The attack requires no authentication — any visitor can exploit a vulnerable form configuration.
via The Hacker News
