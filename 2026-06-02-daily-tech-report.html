Burst Statistics CVE-2026-8181: Active Exploitation — 7,400 Attacks Blocked in 24 Hours

Security

The Burst Statistics privacy-focused analytics plugin (200,000+ active installs) has a critical authentication bypass vulnerability (CVSS 9.8). An unauthenticated attacker who knows any admin username can send a single HTTP request to obtain a WordPress Application Password, achieving full admin takeover. The flaw exists in versions 3.4.0–3.4.1 in the is_mainwp_authenticated() function. Wordfence blocked 7,400+ attacks in the past 24 hours. Patched in version 3.4.2 (released May 12). Free Wordfence users don't get firewall protection until June 7.

Why it matters: If any client site uses Burst Statistics, update to 3.4.2 immediately. This is actively exploited in the wild. Even if you don't use Wordfence, the plugin update alone closes the vulnerability. Check all client sites today.
via Managed-WP / Wordfence
