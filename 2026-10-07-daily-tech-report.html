WordPress 7.1.3 Security Release — 7 Vulnerabilities Patched

Security

WordPress 7.1.3 dropped on October 6 with 7 security fixes and 4 bug fixes. Critical issues patched include a stored XSS on the Comments admin page, a second-order SQL injection in WXR exports, a DoS issue in WP_Http::make_absolute_url(), unauthorized comment disclosure on private posts, an XSS via Imgur embeds, an author-role post-stickying bypass, and an action name collision via forgeable parameters. Backports are available through the 4.7 branch.

Why it matters: The stored XSS and SQL injection vulnerabilities are exploitable and affect all WordPress sites. Update every client site immediately. The SQL injection in WXR exports is particularly concerning if you use export/import workflows for site migrations.
via WordPress.org
