OpenAI Assistants API Officially Sunset — No Grace Period

Breaking

The OpenAI Assistants API was permanently shut down on August 26, 2026. All calls to /v1/assistants, /v1/threads, and /v1/threads/runs now return errors. The replacement is the Responses API (plus the Conversations API for chat history). No automated migration tool is provided — Threads must be rebuilt manually.

Why it matters: If any client project or internal tool still calls the Assistants API, it is broken now. Check your codebase and any third-party plugins that may have depended on it. Migration to the Responses API is mandatory.
via OpenAI Developer Community

Bricks 2.4 Beta: Native MCP Lets Claude Code Build Bricks Pages Directly

Key

Bricks 2.4 beta introduces "AI Abilities" — a native MCP server that exposes builder actions to AI clients. Claude Code, Cursor, and Copilot can now create and edit Bricks pages, templates, components, navigation menus, design systems, and WooCommerce setups directly. The MCP server reads your active breakpoints, CSS variables, and global classes before generating anything, using native Bricks container elements with BEM class naming.

Why it matters: This is a game-changer for your workflow. Instead of Claude Code generating raw HTML/PHP that you manually port into Bricks, it can now build inside Bricks natively — respecting your design system, using your existing components, and outputting real Bricks element structures. The initial ability set covers pages, elements, templates, components, global data, design systems, dynamic data, query loops, nav menus, WooCommerce, and HTML-to-Bricks conversion.
via Bricks Builder
