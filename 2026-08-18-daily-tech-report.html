WordPress 7.0.4 Patches Critical RCE via Imagick/Ghostscript

Security

WordPress 7.0.4 fixes CVE-2026-65640 (CVSS 8.8), a high-severity authenticated remote code execution vulnerability. An attacker with Author-level access can upload a malicious PNG that's actually a PostScript file, exploiting Imagick + Ghostscript to execute arbitrary code. Backported to all branches back to 4.7.

Why it matters: Any WordPress site using Imagick with Ghostscript is vulnerable. Author-level access is a low bar — contributor accounts, guest authors, or compromised credentials could trigger this. Update all client sites to 7.0.4 immediately via Dashboard → Updates. This supersedes 7.0.3 which patched 12 other vulnerabilities including a login screen XSS.
via SecurityWeek
