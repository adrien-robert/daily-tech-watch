Google Imagen 4 API Shuts Down Today

Breaking

Three Imagen 4 model endpoints (imagen-4.0-generate-001, imagen-4.0-ultra-generate-001, imagen-4.0-fast-generate-001) are permanently removed today, August 17. Any app calling generate_images() with these models will get a hard error, not a deprecation warning. The API shape has changed entirely.

Why it matters: If any client project or internal tool uses Imagen 4 for image generation, it breaks today. Migrate to gemini-3.1-flash-image immediately — the new endpoint uses a different API shape, so it's not a drop-in replacement.
via Google AI Developers / Kingy AI

Anthropic Explains Claude Text Watermarking System

Update

Anthropic published a detailed blog post on August 15 explaining how its SynthID-based text watermarking works. Invisible watermarks are embedded in all text from models released after August 2, complying with the EU AI Act. The marks survive copy-paste but are imperceptible to readers. The system applies globally, not just in Europe. Some paying users have canceled subscriptions in protest.

Why it matters: All Claude-generated content now carries an invisible machine-readable watermark. For agency work, this means client deliverables written with Claude could be flagged by detection tools. Consider this when using Claude for client-facing content drafts.

OpenAI Assistants API Sunset in 9 Days

Deadline

The OpenAI Assistants API will permanently stop working on August 26, 2026 — just 9 days from today. All /v1/assistants, /v1/threads, and related endpoints will return errors. Migration requires rebuilding with the Responses API and Conversations API. No automated migration tool is provided; threads must be recreated manually. Vector stores and files can be re-pointed.

Why it matters: If any client project or internal tool uses the Assistants API, you have 9 days to migrate. This is a hard cutoff with no grace period. Audit your projects now and switch to the Responses API.
via OpenAI Developer Community
