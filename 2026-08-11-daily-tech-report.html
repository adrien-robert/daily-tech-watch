WordPress 7.0.3: 12 Security Vulnerabilities Patched

Security

WordPress 7.0.3, released August 6, is a security-only release fixing 12 vulnerabilities. The most critical is CVE-2026-64638 (CVSS 8.9) — a pre-authentication reflected XSS on the login screen that can lead to PHP code execution via the plugin/theme editor. Other fixes cover stored XSS, privilege escalation, SSRF, CSS injection, and email verification bypass. Auto-updates have been force-enabled. Affected versions go back to WordPress 4.7.

Why it matters: The login-page XSS is exploitable without authentication and can escalate to full site compromise. If any client sites have auto-updates disabled, patch manually NOW. Verify all sites are on 7.0.3 today.
via Patchstack

Critical Plugin Vulns: Ajax Load More (9.1) & Ajax Search Lite (9.8)

Security

Two critical plugin vulnerabilities were disclosed on August 10. Ajax Load More (CVE-2026-15360, CVSS 9.1) has a critical severity issue. Ajax Search Lite through version 4.14.4 (CVE-2026-28139, CVSS 9.8) has an unauthenticated PHP Object Injection vulnerability, patched in version 4.14.5. Both are widely-used WordPress plugins.

Why it matters: CVSS 9.8 means critical — unauthenticated attackers can exploit Ajax Search Lite without any credentials. Check all client sites for these plugins and update immediately. Run wp plugin list --status=active across your sites to audit.
via CVE Brief
