Anthropic Splits Billing: Programmatic Usage Gets Separate Credit Pool on June 15

Breaking

Starting June 15, Claude Agent SDK, claude -p, Claude Code GitHub Actions, and all third-party apps built on the Agent SDK will draw from a dedicated monthly credit pool — separate from your interactive chat subscription. Pro users get $20/month, Max 5x gets $100, Max 20x gets $200. Once exhausted, programmatic usage stops unless you enable "extra usage" at standard API rates. Unused credits do not roll over.

Why it matters: If you use Claude Code heavily via API, GitHub Actions, or third-party tools (Cursor, Cline), your workflow may hit limits sooner than expected. Review your current programmatic usage now and budget for the June 15 transition. Consider enabling "extra usage" billing as a safety net.

Deadline

Code completions and next-edit suggestions remain unlimited, but Chat, CLI, cloud agents, Spaces, and Spark will consume credits. Monthly Pro/Pro+ plans auto-migrate on June 1.
