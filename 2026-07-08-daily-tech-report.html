Kirki Plugin Critical Vulnerability — Actively Exploited

Security

CVE-2026-8206 (CVSS 9.8) in the Kirki Freeform Page Builder plugin allows unauthenticated admin account takeover via a flawed password reset mechanism. Affects versions 6.0.0–6.0.6, fixed in 6.0.7. Active exploitation confirmed — Wordfence reported 59 blocked attacks in a single 24-hour period. The vulnerability requires zero authentication or user interaction to exploit.

Why it matters: If any client site uses Kirki, update to 6.0.7 immediately. After updating, force-logout all users and require password resets for admins. The vulnerability has been in the wild since June 2 — any site running 6.0.0–6.0.6 during that period should be audited for compromise.
via CyberSecurity News
