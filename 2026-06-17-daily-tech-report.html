Kirki Plugin CVE-2026-8206 Under Active Exploitation (CVSS 9.8)

Security

The Kirki Freeform Page Builder plugin (500K+ installs) has a critical unauthenticated privilege escalation via its password reset endpoint. Attackers can supply their own email to hijack admin accounts. Patched in v6.0.7 (May 18), but Wordfence reports 59 blocked attacks within a 24-hour window — exploitation is ongoing. Approximately 150,000 sites still run vulnerable versions.

Why it matters: If any client site uses Kirki (common in customizer-heavy themes), update to 6.0.7+ immediately. Audit admin user accounts and check for unauthorized plugins or web shells. The flaw is trivial to exploit with a single REST API request.
via CyberSecurity News
