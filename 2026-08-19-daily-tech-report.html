Critical Pre-Auth XSS in WordPress Core (CVE-2026-64638)

Security

WordPress 7.0.3 (released August 12) patches 12 vulnerabilities including CVE-2026-64638, a critical pre-auth reflected XSS on the login screen (CVSS 8.9) that can chain to PHP code execution when targeting a logged-in admin. Why it matters: Any WordPress site not yet on 7.0.3+ is exposed. The attack requires social engineering but the pre-auth vector makes it high-risk. Update all client sites immediately if not already done.
