Claude Code v2.1.224 — Self-Hosted Environments & Cross-Session Messaging

New

Anthropic shipped a major Claude Code release introducing self-hosted environments (claude self-hosted-runner) that let Team and Enterprise organizations run Claude Code web, mobile, and desktop sessions on their own infrastructure. The same release adds cross-session messaging via SendMessage and ListAgents, plus archive plugin sources for installing plugins from zip over HTTPS with optional SHA-256 pinning.

Why it matters: Self-hosted runners mean your Claude Code sessions can run on a machine with direct access to staging environments, WP-CLI, internal databases, and private repos. No code or client data leaves your network. Cross-session messaging opens up multi-agent workflows where specialized sessions collaborate on complex tasks.
