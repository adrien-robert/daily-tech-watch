Rackspace shuts down its Spot cloud after a breach exposed customer Kubernetes secrets

🔒 Security

Attackers used compromised credentials on 17 Nov to reach Rackspace Spot, where they could read Kubernetes Secrets and files on storage volumes. Rackspace will discontinue the service on 8 Dec 2026 at 5 PM Central Time and tells customers to treat tokens, kubeconfigs and Secrets as compromised. It says it has found no sign of access to its core systems.

Why it matters: Only relevant if a client or tool of yours runs on Rackspace Spot; if so, rotate every credential and migrate before 8 Dec. Otherwise, nothing to do.

MCP's Tasks and Elicitation reach general availability as the protocol passes 700 million monthly downloads

🔄 Update

On the protocol's second anniversary, Anthropic reported more than 700 million monthly MCP SDK downloads and over 10,000 MCP connectors for Claude, according to The Decoder. Tasks let a server run a long job in the background, and Elicitation lets a running process pause to ask the user for missing details. Both reached general availability after a public test in October.

Why it matters: MCP servers you use or build, including WordPress ones, can now run long jobs and ask for missing input instead of failing. Expect new versions of those servers to start using both.

via The Decoder · published Tue 24 Nov

Claude Code 2.1.332 adds skills from MCP servers and a hook that can block a skill's shell commands

🔄 Update

Version 2.1.332, dated 25 Nov, adds skills served by MCP servers in beta, shown as server:skill in the / menu. It also adds a PreSkillShellCommand hook event that can refuse a skill's or command's inline shell commands as it loads. On 2.1.331 and older, a settings file naming that event opens a dialog at start.

Why it matters: An MCP server can now ship its own skills, so a WordPress or Bricks MCP could bring ready-made workflows. If you share settings across machines, update them together to avoid the startup dialog.

via Claude Code changelog · published Wed 25 Nov

Anthropic lets Claude Artifacts be installed as standalone Mac and Windows apps, in beta

🆕 New

Artifacts built in chat can now be kept in the dock as desktop apps, which requires the latest Claude app for macOS or Windows. The apps can use OS APIs, connectors and Claude itself, for example to add menu bar items or send notifications. A free account is enough, according to The Decoder.

WordPress 7.2 adds three read-only core abilities for content, users and settings

🔧 Tool

A dev note from 24 Nov lists core/content-query, core/users-query and core/settings-get, which add to the three informational abilities from WordPress 6.9. Content and user queries take filters, fields and pagination, and return a WP_Error if the input is invalid or the user lacks permission. More read and write abilities are planned for later releases.

Why it matters: These give AI agents a standard, permission-checked way to read a site's posts, users and settings without a custom plugin. They are worth trying on staging once 7.2 ships.

via Make WordPress Core · published Tue 24 Nov

Google pre-announces a December 2026 core update, hours after finishing November's

❗ Important

Google posted the December 2026 core update on its Search Status Dashboard on 24 Nov, saying it will roll out sometime in December. It focuses on ranking relevant content, including for longer and more complex questions, and on personalised results. The November 2026 core update was declared complete the same day.

Why it matters: Note the baseline rankings and traffic of client sites now, so you can tell November's effects from December's. Avoid judging a site's SEO work until both updates have settled.

via Search Engine Journal · published Tue 24 Nov

Google documents advance notice for ranking updates and a feedback route in Search Console

🆕 New

A new Ranking section on Search Central says Google will give advance notice of significant ranking updates and actionable policy changes on the Search Status Dashboard. Verified site owners can send feedback on an update through Search Console, and sites serving UK users that were manually removed from the index can appeal from 17 Dec.

Why it matters: The Search Status Dashboard has an RSS feed, so you can follow it to get warning before client rankings move. The feedback form needs a verified owner, so check you are verified on client properties.

via Search Engine Journal · published Tue 24 Nov
