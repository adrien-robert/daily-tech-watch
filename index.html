1Password says an attacker used a hijacked GitHub account to steal customer records

🔒 Security

1Password disclosed on 25 Nov that an employee's GitHub account was compromised, used to access private source code and push malicious code to backend services that downloaded account records. Names, email addresses and some invitation and recovery tokens were taken; vault contents and the keys protecting them were not accessed.

Why it matters: If you or clients use 1Password, no password change is required, but expect phishing that mentions invitations or account recovery and ignore any you did not request.

via 1Password · published Wed 25 Nov

Drupal installer flaw is exploited in the wild and added to CISA's exploited list

🔒 Security

Drupal says CVE-2026-132165, which lets an anonymous user abuse install.php to reinstall a site and gain remote code execution, was exploited on live sites from 19 Nov. CISA added it to its Known Exploited Vulnerabilities catalog on 24 Nov.

Why it matters: Not WordPress, but any Drupal site you host or inherit needs the latest Drupal release; until then, block /core/install.php at the web server.

via BleepingComputer · published Wed 25 Nov

Palo Alto confirms PAN-OS firewalls are hit by the PHP2Shell and Fragnesia attack chain

🔒 Security

Palo Alto Networks said on 25 Nov that CVE-2026-46300 (Fragnesia, a Linux kernel flaw) is exploited against PAN-OS devices whose management interface is exposed to the internet. Attackers chain it with the PHP2Shell flaws CVE-2026-109618 and CVE-2026-109619, and fixes exist for PAN-OS 10.2, 11.1, 11.2, 12.1 and 12.2.

Why it matters: Relevant only if a client runs a Palo Alto firewall; the general lesson is that PHP remote-code flaws are being chained with local root bugs, so keep host PHP and kernels current.

WordPress core adds limits so revision comparisons of huge posts stop timing out

🔄 Update

A core dev note from 25 Nov says comparing revisions of a very large post could take minutes or run out of memory; a one-line 200 KB table took 48 seconds. Past new limits the diff still shows every line but skips word-level highlighting, and the limits can be raised through wp_text_diff() arguments or the revision_text_diff_options filter.

Why it matters: Heavy pages built with large data tables or imported content will stop freezing the revisions screen; raise the limits only if a client needs the finer diff.

via Make WordPress Core · published Wed 25 Nov

Google documents pageburst, a Google Ads crawler that ignores robots.txt

❗ Important

Google added 12 existing user agents to its crawler docs on 23 Nov, including pageburst, which renders pages for Google Ads quality and landing-page safety and ignores robots.txt. Its two strings look like ordinary browsers and do not contain "Googlebot".

Why it matters: Bot rules or firewall filters keyed on "Googlebot" will not catch it; if you run ads for clients, do not block it, and verify requests by Google's published IP ranges.

via Search Engine Journal · published Thu 26 Nov

Firefox 161 adds per-site VPN rules and a one-click clear-data flame button

🆕 New

Firefox 161, dated 24 Nov, lets users set sites on which the built-in VPN is always on or always off. It also adds a flame button in the toolbar that clears session data in one click, rolling out gradually.

Why it matters: Nothing to change in your sites; the flame button is handy when testing in a clean browser state.
