Otter Gutenberg Blocks Critical Auth Bypass — CVE-2026-2892 (CVSS 7.5)

Security

A critical broken authentication vulnerability was disclosed in Otter – Gutenberg Blocks (all versions up to 3.1.4). The get_customer_data method trusts an unsigned o_stripe_data cookie without server-side Stripe API verification, allowing unauthenticated attackers to bypass purchase-gated content by forging the cookie with a product ID exposed in the checkout block's HTML source.

Why it matters: If you use Otter's Stripe integration on any client site, unauthenticated visitors can access premium content without paying. Update to version 3.1.5 immediately and audit your Stripe-gated pages for unauthorized access in server logs.
via Managed-WP
