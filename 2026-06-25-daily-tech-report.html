Critical Auth Bypass in Service Finder Bookings Plugin (CVE-2025-5947)

Security

A critical vulnerability (CVSS 9.8) in the Service Finder Bookings plugin (versions ≤6.0) allows unauthenticated attackers to log in as any user, including administrators, due to improper cookie validation. The flaw enables full site takeover without any credentials.

Why it matters: CVSS 9.8 is near-maximum severity. If any client site uses Service Finder, update or deactivate the plugin immediately. Even if you don't use it, this is a reminder to audit cookie-based authentication in any custom plugins.
via Security Affairs

Bricks Builder 2.3.8: Component Slots and Query Loop Fixes

Update

Bricks 2.3.8 (June 23) focuses on stability: fixes for component slot rendering, query loop issues, Gutenberg component blocks, and builder rendering. Notable additions include blocking recursive component insertion (preventing render loops) and improved SEO analysis that now correctly counts full post content with Gutenberg More blocks.

Why it matters: The component slot and query loop fixes address pain points in complex Bricks layouts. The recursive component protection prevents a class of hard-to-debug rendering issues. Update your Bricks sites.

Deadline
