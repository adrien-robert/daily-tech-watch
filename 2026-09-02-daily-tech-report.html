DebugMaster Pro: Sophisticated WordPress Backdoor Disguised as Debug Plugin

Security

Sucuri researchers discovered a backdoor disguised as a WordPress debugging plugin called "DebugMaster Pro". It creates a hidden admin account ("help") with hardcoded credentials, sends server details to attackers, injects malicious code visible only to visitors, and hides itself from the plugin list and user queries. A companion wp-user.php file recreates the admin account if it's deleted.

Why it matters: This is a direct threat to WordPress agencies. Audit all client sites for: (1) a plugin named "DebugMaster Pro" or similar debug-themed plugins you didn't install, (2) a user account named "help", and (3) a wp-user.php file in the WordPress root. Both the plugin directory and the PHP file must be removed simultaneously to prevent reinfection.
via Sucuri
