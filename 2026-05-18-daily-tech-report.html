WordPress 7.0 RC4 — Block Editor Always Iframed, PHP 7.4 Minimum

Breaking

WordPress 7.0 launches May 20 with breaking changes: the block editor is now always iframed (breaking meta boxes and admin JS), Block API v3 is enforced, DataViews replaces WP_List_Table on core admin screens, and the Interactivity API renames effect-to-watch. Real-time collaboration was removed. Scripts must move from admin_enqueue_scripts to enqueue_block_editor_assets. Minimum PHP raised to 7.4, with 8.3 recommended.

Why it matters: The iframed editor is the biggest breaking change — any custom admin panels, meta boxes, or JS that hooks into the editor needs testing. Bricks 2.3.5 already includes a WP 7.0 CSS fix for boxed layouts, so update Bricks first, then test. Audit all client server PHP versions today.
