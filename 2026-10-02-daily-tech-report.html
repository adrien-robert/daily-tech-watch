WP2Shell RCE Chain Still Under Active Exploitation — Patch to 7.0.2 Now

Security

The WP2Shell vulnerability chain (CVE-2026-60137 + CVE-2026-63030) continues to be actively exploited in the wild. The SQL injection + REST API route-confusion chain enables unauthenticated remote code execution on WordPress 6.8.0–6.8.5, 6.9.0–6.9.4, and 7.0.0–7.0.1. Fixes are available in 6.8.6, 6.9.5, and 7.0.2. Public PoC exploits are widely available.

Why it matters: If any of your client sites are running affected versions, they are vulnerable to complete takeover. WordPress.org has enabled forced auto-updates for supported installations, but custom-hosted or managed sites may need manual intervention. Verify every site today.
via SecurityWeek

Reddit Kills RSS Feeds and JSON API Endpoints

Breaking

Reddit has progressively shut down open access: .json endpoints return 403, OAuth access is closed, and RSS feeds are now severely rate-limited (429 errors for standard user agents). All third-party access is being forced through Reddit's new Developer Platform. The changes affect bots, scrapers, and content aggregation tools.

Why it matters: If you use Reddit as a content source for client projects, content curation workflows, or social listening tools, existing integrations will break. Any n8n/Make automations pulling Reddit data need to migrate to the Developer Platform or find alternative data sources.
